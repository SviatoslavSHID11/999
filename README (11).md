# Java: семестр 1

Практичні та домашні завдання з Java (Святослав Німченко).

## Структура

| Папка | Зміст |
|-------|-------|
| `practice02` | Змінні та типи даних |
| `practice03` | Умовні оператори, 5 домашніх завдань |
| `practice04` | Цикли, 5 домашніх завдань |
| `practice05` | Масиви, домашні завдання |
| `practice06` | Класи та об'єкти, 5 домашніх завдань |
| `practice07` | Конструктори та ООП, навчальні завдання |

У кожній папці `practiceXX` лежать `README.md`, `Homework.md` і папка `homework` з кодом.

## Запуск

Відкрийте папку проєкту в IntelliJ IDEA (папка `src` позначена як Sources Root) і запускайте потрібний клас через `main`.
